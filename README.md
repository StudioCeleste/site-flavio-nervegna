# Site Flavio Nervegna

Portfolio vitrine de Flavio Nervegna — design culturel.

Site statique : `index.html` (HTML, CSS et JavaScript dans un seul fichier), images dans `img/`.
Aucune étape de build : le dossier est servi tel quel.

## Mettre à jour

Modifier `index.html` ou remplacer une image dans `img/`, puis pousser sur la branche `main` :
Vercel redéploie automatiquement.
